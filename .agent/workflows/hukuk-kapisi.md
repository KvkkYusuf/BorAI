# /hukuk-kapisi — Metin ve özellik kontrolü
Verilen UI metni, e-posta şablonu, LLM prompt'u veya özellik tanımı için kontrol et:
1. "al/sat/tut/hedef fiyat/garanti/kesin" benzeri yönlendirici ifade var mı?
2. Kullanıcıya özel risk/hedef/portföy verisi toplanıyor veya sonucu kişiselleştiriyor mu?
3. Kaynak, veri zamanı, gecikme ve belirsizlik gösteriliyor mu?
4. Lisanssız veri/logo/marka kullanımı var mı?
Sonuç: GEÇTİ / DÜZELT / DURDUR + gerekçe. Şüphede "avukata sor" olarak işaretle; karar verme.
