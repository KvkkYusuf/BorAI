## 14. Test stratejisi

- [x] Birim testleri: indikatörler, fiyat dönüşümleri, veri temizleme, yetkilendirme ve uyarı koşulları.
- [x] Entegrasyon testleri: veri sağlayıcı adaptörü, veritabanı, e-posta, kuyruk ve API.
- [x] Sözleşme testleri: sağlayıcı/API şema değişiklikleri.
- [x] Zaman serisi testleri: sıra, eksik veri, kurumsal işlem, piyasa tatili ve saat dilimi.
- [x] Model testleri: veri sızıntısı, tekrarlanabilirlik, baseline kıyası ve uç durumlar.
- [x] Güvenlik testleri: erişim kontrolü, oturum, hız sınırı, input validation.
- [x] E2E testleri: kayıt/giriş, hisse arama, grafik açma, izleme listesi, uyarı kurma, hesap silme.
- [x] Yük ve dayanıklılık testi yap; API sağlayıcı kesintisini simüle et.
- [x] Test verilerinde gerçek kullanıcı bilgisi kullanma.
- [x] Kritik akışlar için minimum kapsama hedefi koy; kapsama oranını kalite kanıtı olarak tek başına görme.
